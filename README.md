# George's Restaurant · Digital Menu

Multilingual QR menu for **George's Restaurant**, El Madroñal, Costa Adeje, Tenerife.

Chinese & Mediterranean · EN / ES / DE / FR / IT / CA · prices in €.

## Live (after Netlify drop)

Live site: **https://georgesadeje.netlify.app**

## Local

```bash
python3 -m http.server 8790
open http://127.0.0.1:8790/
```

## Deploy

1. Open https://app.netlify.com/drop
2. Drag `~/Desktop/georges-restaurant-netlify`
3. Rename site → **georgesadeje**
4. Point QR codes at https://georgesadeje.netlify.app (or georgesadeje.com once registered)

## Features

- Dual kitchen filter (Asian / Mediterranean / All) with dish counts
- Search (accent-insensitive) by name, number or description
- Open / closing-soon badge on Canary Islands time — **open daily**
- Dish descriptions from the 2026 printed menu
- Vegetarian + spicy markers
- Printed-menu photo gallery (including allergen table)
- Visit card, Maps embed, WhatsApp reservation, call, share
- Italian + Catalan + ES / DE / FR
- PWA (Add to Home Screen) + offline service worker
- Restaurant JSON-LD (hours, email, geo, Tripadvisor)

Hours follow the restaurant’s current public listing (Tripadvisor claimed + Instagram “open everyday”). Confirm holidays by phone.
